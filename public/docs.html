SYRIX FLIX — API

Documentation d'intégration pour développeurs

BASE URL 
https://api.votre-domaine.com/api/v1

Remplacez par l'URL de votre déploiement du backend SYRIX FLIX (ne pointez jamais directement sur l'IP du VPS dans vos intégrations — utilisez toujours un nom de domaine).

1. Deux modes d'authentification

a) Token de session (app mobile) — délivré par POST /auth/login, envoyé en en-tête :

Authorization: Bearer <token>

b) Clé API développeur (sites/apps tierces) — générée depuis l'écran Profil, envoyée en en-tête :

X-API-Key: SYRIX_API_KEY_xxxxxxxxxxxxxxxx

2. Clé API liée à un domaine, pas à une IP

Contrairement à un système de liste blanche par IP, la clé API SYRIX FLIX est verrouillée sur un nom de domaine — celui de votre site (ex: movie.votresite.com), et non sur l'IP du VPS qui héberge cette API.

1
Générez votre clé depuis l'écran Profil de l'app (bouton "Générer une clé API"). Elle est vide par défaut et n'est créée qu'à votre demande.
2
Auto-détection du domaine : si vous ne renseignez pas de domaine à la création, la clé se verrouille automatiquement sur le domaine détecté (en-tête Origin/Referer) lors de votre tout premier appel réussi.
3
Ou déclarez-le manuellement, par exemple via une variable d'environnement dans votre propre site : 
# .env de votre site "movie syrix"
SYRIX_API_KEY=SYRIX_API_KEY_xxxxxxxxxxxxxxxx
SYRIX_ALLOWED_DOMAIN=movie.votresite.com
puis en confirmant ce domaine via PATCH /profile/api-key/domain.
Une fois verrouillée, la clé refuse toute requête provenant d'un autre domaine (error.code = "domain_mismatch"). Pour changer de domaine, mettez à jour PATCH /profile/api-key/domain ou révoquez/régénérez la clé.

Toutes ces routes relaient et normalisent le catalogue source (mêmes champs, mêmes codes d'erreur : not_found, wrong_type, no_servers, source_unavailable).

4. Enveloppe de réponse

// Succès
{ "success": true, "data": ... }

// Erreur
{ "success": false, "error": { "code": "not_found", "message": "..." } }

5. Exemple d'intégration (JavaScript)

const BASE = "https://api.votre-domaine.com/api/v1";
const API_KEY = process.env.SYRIX_API_KEY;

async function getMovies(page = 1) {
  const res = await fetch(`${BASE}/movies?page=${page}`, {
    headers: {
      "X-API-Key": API_KEY,
      // Origin est envoyé automatiquement par le navigateur ;
      // côté serveur (Node), ajoutez-le manuellement si nécessaire :
      "Origin": "https://" + process.env.SYRIX_ALLOWED_DOMAIN,
    },
  });
  const json = await res.json();
  if (!json.success) throw new Error(json.error.message);
  return json.data;
}
